<a id="working-style"></a>

## <samp>working style</samp>

- I build tools around the user's actual workflow, not the workflow I wish they had.
- I prefer boring reliability over heroic debugging at 4:59 PM.
- I write docs because "it was obvious at the time" is not a support strategy.
- I like small, focused utilities that do one job well and do not require a ceremony to run.
- I test edge cases because data has a sense of humor and I refuse to let it be the funniest person in the room.
